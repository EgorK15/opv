# Операция: Query (запрос к вики)

Отвечай **на основе вики** (которая уже скомпилирована из источников), а не пересказом
сырых книг с нуля. Следуй конвенциям `CLAUDE.md`.

## Шаги
1. **Навигация.** Прочитай `wiki/index.md`, найди релевантные страницы по теме вопроса.
   При необходимости — `grep`/поиск по `wiki/` по ключевым терминам.
2. **Чтение.** Открой найденные страницы концепций/источников/персон. Перейди по их
   `[[ссылкам]]`, если нужен контекст (например, базовые операции `[[gaxpy-и-saxpy]]`).
3. **Синтез.** Сформулируй ответ: суть без воды — определения, формулы (LaTeX), шаги
   алгоритма, оценки, выводы. **Каждый ключевой тезис — с цитатой** на страницу вики и
   через неё на `[[Источник]] §`. Если данные на страницах расходятся — укажи это.
4. **Форма ответа** по вопросу: текст, сравнительная таблица, список, при необходимости —
   диаграмма (matplotlib) или слайды (Marp). Для сравнений алгоритмов таблица обычно лучше.
5. **Зафайлить обратно (важно).** Если ответ ценный (сравнение, разбор связи, новый угол) —
   предложи сохранить его как новую страницу `wiki/concepts/<...>.md` (или `wiki/synthesis`-дополнение),
   проставь ссылки, обнови `index.md` и допиши в `log.md`:
   `## [ГГГГ-ММ-ДД] query | <краткая тема>` + что найдено/создано.
   Так исследования накапливаются в базе, а не теряются в чате.

## Если в вики пробел
Если релевантной страницы нет, но тема есть в `markdown/` источниках — ответь из источника
и предложи **доингестить** недостающее (`/wiki-ingest`). Если темы нет нигде — скажи прямо
(не выдумывай), при необходимости пометь как кандидата на веб-поиск.
