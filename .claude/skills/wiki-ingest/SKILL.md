# Операция: Ingest (загрузка источника в вики)

Цель — не просто «положить» источник, а **скомпилировать знание один раз** и встроить его
в существующую вики: обновить связанные страницы, отметить расхождения, усилить синтез.
Следуй схеме в корневом `CLAUDE.md` (структура, frontmatter, ссылки, LaTeX, цитирование).

## Перед началом
1. Прочитай `wiki/index.md` (что уже есть) и хвост `wiki/log.md` (`grep "^## \[" wiki/log.md | tail -5`).
2. Определи источник(и) в `markdown/`. Для книг — используй заголовки (`grep -nE '^#' <файл>`),
   чтобы построить карту разделов §, и список рисунков (`grep -nE '!\[' <файл>`).

## Шаги
1. **Чтение.** Прочитай источник по разделам (целевыми Read с offset/limit — файлы большие).
   Для лекций сверяй смысл с методичками (OCR грубее).
2. **Обсуждение (если пользователь рядом).** Кратко перечисли ключевые темы/выводы и что
   планируешь создать/обновить. При батч-ingest без супервизии — пропусти и действуй.
3. **Страница источника** `wiki/sources/<источник>.md`: frontmatter `тип: источник`, краткое
   содержание, карта разделов §, ключевые алгоритмы/понятия (со ссылками `[[...]]`),
   охваченные экзаменационные темы.
4. **Страницы концепций** `wiki/concepts/<концепция>.md`: на каждый значимый алгоритм/метод/
   метрику. Если страница уже есть — **дополни** её взглядом нового источника (а не перезаписывай),
   добавь цитату `[[Источник]] §X.Y`. Структура: определение → формулы/свойства → шаги
   алгоритма → сложность/оценки → `## Связи` ([[ссылки]]) → `## Расхождения` (если методичка
   и лекции расходятся) → источники. Формулы в LaTeX (без литеральных `<`/`>` — `\lt`,`\gt`).
   Вставляй относящиеся рисунки из `markdown/<папка>/_page_*.jpeg`.
5. **Страницы персон** `wiki/people/<имя>.md`: кто, вклад (классификация/метод/алгоритм),
   ссылки на связанные концепции.
6. **Кросс-ссылки.** Пройди по затронутым страницам и добавь взаимные `[[ссылки]]`
   (концепция↔концепция, концепция↔персона, концепция↔источник). Базовые операции
   (`[[gaxpy-и-saxpy]]`, `[[модификация-матрицы-внешним-произведением]]`) — линкуй везде,
   где они используются.
7. **`index.md`.** Добавь/обнови строки-каталог по категориям (источники / концепции /
   персоны): ссылка + однострочное описание.
8. **`log.md`.** Допиши запись:
   `## [ГГГГ-ММ-ДД] ingest | <Источник>` + 2–4 строки: что создано/обновлено (счётчики),
   замеченные расхождения, открытые вопросы.
9. **`synthesis.md` / `overview.md`.** Если источник меняет общую картину — обнови сквозной
   тезис и карту.

## Параллелизм при батч-ingest
Если ингестишь сразу много/большие источники — можно распараллелить субагентами, **но**
во избежание конфликтов записи: назначай каждому субагенту **непересекающийся набор
страниц** (например, по кластерам концепций), а `index.md`/`log.md`/`synthesis.md` сводит
один писатель (ты) после возврата субагентов.

## Критерии качества
- Факты привязаны к `[[Источнику]] §`. Расхождения методичка/лекции зафиксированы.
- Нет страниц-сирот: у каждой новой страницы есть входящие ссылки (минимум из `index.md`
  и из связанной концепции/источника).
- Формулы корректны и рендерятся; рисунки ведут на существующие файлы.
