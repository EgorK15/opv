# LLM Wiki — Основы параллельных вычислений

Это персональная база знаний (паттерн «LLM Wiki») по курсу **«Основы параллельных
вычислений»** и вычислительной линейной алгебре. Построена по идее из `llm_wiki.txt`.
Язык базы — **русский**. Формулы — **LaTeX**.

## Три слоя

1. **Raw sources (источники, неизменяемые)** — конвертированные в Markdown книги и
   лекции в папке `markdown/`. Агент **только читает** их, никогда не меняет. Это
   источник истины:
   - `[[Модели]]` — Головашкин, «Модели в теории параллельных вычислений», 2019;
   - `[[Векторные алгоритмы]]` — Головашкин, «Векторные алгоритмы вычислительной линейной алгебры»;
   - `[[Параллельные алгоритмы]]` — Головашкин, «Параллельные алгоритмы вычислительной линейной алгебры»;
   - `[[Лекции]]` — конспект «Основы параллельных вычислений» (OCR грубее, чем у методичек — сверяй с методичками).
2. **Wiki (`wiki/`, генерируется агентом)** — взаимосвязанные Markdown-страницы. Агент
   владеет этим слоем целиком: создаёт, обновляет, кросс-ссылается, поддерживает
   консистентность. Человек читает (в Obsidian), агент пишет.
3. **Schema (этот файл)** — правила структуры, конвенции страниц и рабочие процессы.

## Структура `wiki/`

```
wiki/
  overview.md        # карта предметной области, точка входа
  synthesis.md       # сквозной тезис: как всё связано (уровни сложности, архитектура→алгоритм)
  index.md           # КАТАЛОГ всех страниц (по категориям, со ссылкой и однострочным описанием)
  log.md             # ХРОНОЛОГИЯ: append-only журнал (ingest/query/lint)
  sources/           # по странице на каждый источник (краткое содержание + структура §)
  concepts/          # концепции, алгоритмы, методы, метрики (основная масса)
  people/            # персоны (Флинн, Хокни, Голуб, Петри, Штрассен, Амдал, …)
```

## Конвенции страниц

- **Имя файла** — читаемый русский слаг с дефисами; латинские термины сохраняем
  (`LU-разложение.md`, `gaxpy-и-saxpy.md`, `классификация-Флинна.md`, `сети-Петри.md`).
- **Frontmatter (YAML)** в каждой странице (для Dataview):
  ```yaml
  ---
  тип: концепция | источник | персона | обзор | синтез
  теги: [разложения, кольцо, ...]
  источники: ["[[Параллельные алгоритмы]] §2.2", "[[Лекции]] §3.2.3"]
  обновлено: ГГГГ-ММ-ДД
  ---
  ```
- **Ссылки** — Obsidian-стиль `[[имя-страницы]]`. Ссылайся щедро: каждое упоминание
  другой концепции/персоны/источника — ссылка. Несуществующая ещё `[[ссылка]]` — это
  нормально, помечает страницу к созданию.
- **Цитирование источника** — после ключевого факта указывай `[[Источник]] §X.Y`.
  Если факт есть в нескольких книгах — перечисли; при расхождении методички и лекций
  приоритет у методичек, расхождение **зафиксируй** явно (раздел «Расхождения»).
- **Формулы** — LaTeX: inline `$...$`, блочные `$$...$$`. **Не используй литеральные
  `<` и `>` внутри математики** (ломает часть рендереров) — пиши `\lt`, `\gt`, `\le`, `\ge`.
- **Рисунки** — если к концепции относится рисунок из источника, вставляй относительной
  ссылкой на файл в `markdown/<папка-книги>/_page_*.jpeg`.
- **Структура страницы концепции** (ориентир): краткое определение → формулы/свойства →
  алгоритм/шаги → сложность/оценки → связи (`## Связи`) → расхождения (если есть) →
  источники.

## Рабочие процессы (operations)

Реализованы как скилы (`.claude/skills/`). Вызывай их по имени.

- **`/wiki-ingest`** — обработать источник: прочитать, обсудить ключевое, создать/обновить
  страницу источника, создать/обновить страницы концепций и персон, проставить
  кросс-ссылки, обновить `index.md`, дописать запись в `log.md`. Один источник трогает
  10–15 страниц.
- **`/wiki-query`** — ответить на вопрос по вики: найти релевантные страницы через
  `index.md`, прочитать, синтезировать ответ с цитатами. Хороший ответ можно зафайлить
  обратно как новую страницу концепции.
- **`/wiki-lint`** — проверка здоровья: противоречия, устаревшие утверждения, страницы-сироты
  (без входящих ссылок), упомянутые но не созданные концепции, недостающие кросс-ссылки.

## Специфика домена (важно)

- Тематика: параллельные вычисления + вычислительная линейная алгебра. Много **алгоритмов**
  (умножение матриц, LU, Холецкий, прогонка), **моделей** (Флинн, Хокни, сети Петри),
  **методов распараллеливания** (ЯПФ, пирамиды, параллелепипеды), **метрик** (ускорение,
  закон Амдала).
- Базовые операции (`saxpy` $z=\alpha x+y$, `gaxpy`/дахру $z=Ax+y$, скалярное произведение,
  модификация матрицы внешним произведением) — фундамент; на них ссылается почти всё.
- Один алгоритм часто разобран в нескольких книгах под разными углами (векторный →
  параллельный). На странице концепции **объединяй** взгляды и помечай, какой источник
  даёт какой аспект.
- OCR лекций местами искажён — реконструируй смысл, сверяясь с методичками; не тиражируй
  явные опечатки.
