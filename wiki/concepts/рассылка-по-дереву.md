# Рассылка данных по дереву

Первый пример параллельного алгоритма у Головашкина: распределение элементов вектора
$a(1:n)$ по $p$ задачам. До начала вектор целиком лежит в задаче 1; по завершении в
задаче $\mu$ ($1\le\mu\le p$) находится часть $a((\mu-1)r+1:\mu r)$, хранимая локально
как $a(1:r)$, где $r=n/p$ (для простоты целое). Полезен для **начального распределения
данных** перед основными вычислениями. [[Модели]] §1.2.3

## Вариант на звезде (не параллельный)

Простейшая [[топологии-сетей|топология коммуникаций]] — **звезда**: первая задача в
цикле рассылает остальным их части.

```
Алгоритм 1.1. Рассылка данных на звезде
Инициализация {a(1:n) — вектор, n — размер, μ — номер задачи,
               p — число задач, r=n/p, топология — звезда}
01 if μ = 1 then              % действия первой задачи
02   for i = 2:p              % обход остальных задач
03     send(a((i-1)r+1 : i·r), i);   % отправка задаче i её части
04   end for
05 else                       % все задачи, кроме первой
06   recv(a(1:r), 1);         % приём своей части от первой
07 end if
```

Недостатки: действия производятся **последовательно** (это ещё не параллельный
алгоритм), а топологию «звезда» при большом $p$ трудно отобразить на реальную сеть
без дополнительной маршрутизации. [[Модели]] §1.2.3

## Вариант на бинарном дереве

Уместнее распределять вектор по **бинарному дереву**, связывающему $p$ задач
(для простоты $\log_{2}p$ — целое). Дерево из $p=8$ задач имеет 4 уровня (нумеруются
сверху вниз 3, 2, 1, 0). На каждом уровне задача отправляет **вторую половину**
оставшегося у неё вектора новому адресату; на каждом шаге вдвое больше задач уже
владеют данными и могут рассылать дальше.

![Бинарное дерево коммуникаций](../../markdown/Головашкин_Д_Л_Модели_в_теории_параллельных_вычислений_2019/_page_22_Figure_2.jpeg)

*Рис. (к §1.2.3). Линейная и ступенчатая модели коммуникаций — при рассылке мелкие
порции выгодно объединять в один пакет.*

```
Алгоритм 1.2. Рассылка данных на бинарном дереве
Инициализация {a(1:n), n, μ, p, r=n/p, топология — бинарное дерево}
01 if μ = 1 then                       % первая задача
02   k = log2(p);                       % верхний уровень дерева
03   for i = k:-1:1                      % спуск по уровням
04     send(a(n/2+1:n), 1 + 2^(i-1));    % отправить вторую половину
05     n = n/2;                          % вектор сокращается вдвое
06   end for
07 else
08   if μ чётное then                   % чётные задачи только принимают
09     recv(a(1:r), μ-1);
10   else                               % остальные нечётные
11     k = 0; q = μ;                     % поиск уровня приёма k
12     while mod(q,2) ≠ 0
13       q = (q+1)/2; k = k+1;
14     end while
15     n = n / 2^(log2(p)-k);            % размер принимаемых данных
16     recv(a(1:n), μ - 2^k);            % приём от задачи μ-2^k
17     for i = k:-1:1                     % затем рассылка вниз по дереву
18       send(a(n/2+1:n), μ + 2^(i-1));
19       n = n/2;
20     end for
21   end if
22 end if
```

Задачи делятся на три множества: **первая** (несколько раз отправляет), **чётные**
(один раз принимают), **остальные нечётные** (вычисляют свой уровень $k$ из теории
графов, принимают, затем рассылают, как первая). [[Модели]] §1.2.3

## Сложность

Главное преимущество дерева — **логарифмическое** число шагов: рассылка завершается
за $\log_{2}p$ уровней вместо $p-1$ последовательных отправок на звезде.

## Упрощения

- Уровень $k$ можно не вычислять (строки 11–16), а **передавать вместе с данными**
  (например, за последним элементом вектора) — принимающая задача извлечёт из посылки
  и размер $n$, и уровень $k$, не зная заранее номера отправителя.
- В [[MPI]] есть готовая процедура рассылки; знакомство с Алгоритмом 1.2 помогает
  понять её «внутреннюю механику». [[Модели]] §1.2.3

## Связи

- [[топологии-сетей]] — звезда и дерево как топологии коммуникаций; почему дерево
  лучше отображается на реальную сеть.
- [[сетевая-деградация-и-коммуникации]] — стоимость коммуникаций (латентность, пакеты).
- [[MPI]] — стандартная реализация коллективной рассылки.
- [[рекуррентные-выражения]] — другой алгоритм с логарифмическим числом шагов
  (свёртка произведения по дереву).
