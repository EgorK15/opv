## Определение (по общим знаниям, вне источников вики)

**Циклическая редукция** (cyclic reduction, метод нечётно-чётной редукции) —
параллельный прямой метод решения СЛАУ с **трёхдиагональной** (и блочно-трёх­
диагональной) матрицей. Идея: на каждом шаге из системы **исключаются неизвестные с
чётными (или нечётными) номерами** — каждое уравнение комбинируется с двумя
соседними так, чтобы выразить связь только между оставшимися неизвестными. Оставшаяся
подсистема — снова трёхдиагональная, но вдвое меньшего размера.

- Процесс редукции повторяется $\approx \log_2 n$ раз (фаза **редукции**), пока не
  останется одно (или несколько) уравнение, решаемое напрямую.
- Затем за столько же шагов идёт фаза **обратной подстановки**: восстанавливаются
  ранее исключённые неизвестные.
- Суммарная глубина — порядка $\log_2 n$ параллельных шагов, что делает метод
  привлекательным для параллельных архитектур (в отличие от $O(n)$-глубины обычной
  [[метод-прогонки|прогонки]]). Цена — больший общий объём арифметики.

> Всё содержание этого раздела — внешнее общее знание, не подтверждённое выданными
> источниками. При появлении источника, излагающего метод, страницу следует
> переписать с точными цитатами и $\S$.
