# Метод Винограда

«Быстрый» алгоритм умножения матриц, предложенный **Шмуэлем Виноградом** в начале
1960-х годов. Идея: снизить число **скалярных умножений** примерно вдвое за счёт
**предвычисленных сумм** парных произведений, ценой полуторакратного роста числа
сложений ([[Векторные алгоритмы]] §1.3). См. также базовое [[умножение-матриц]].

## История

Снижение сложности умножения матриц долго считалось нерешаемой задачей. Виноград
(начало 60-х) первым показал, что число умножений можно сократить вдвое — правда,
общий объём арифметики даже немного вырос, но на практике умножение несколько
ускорилось (умножение дороже сложения). Дальше: [[метод-Штрассена]] (конец 60-х,
$O(n^{2.807})$); метод **Копперсмита–Винограда** (1987, $O(n^{2.376})$; улучшен в
2011 до $O(n^{2.373})$) — последний имеет лишь теоретическую ценность из-за гигантской
константы ([[Векторные алгоритмы]] §1.3).

## Формула

Скалярное произведение строки $A$ на столбец $B$ переписывается через парные суммы:
$$c_{ij} = \sum_{k=1}^{q/2}\bigl(a_{i,2k-1} + b_{2k,j}\bigr)\bigl(a_{i,2k} + b_{2k-1,j}\bigr)
  - \sum_{k=1}^{q/2} a_{i,2k-1} a_{i,2k}
  - \sum_{k=1}^{q/2} b_{2k-1,j} b_{2k,j}. \tag{3}$$

Ключ к экономии: **второе и третье слагаемые предвычисляются заранее**:
- для каждой строки $i$ матрицы $A$ — величина $\text{row}(i)=\sum_{k=1}^{q/2} a_{i,2k-1}a_{i,2k}$
  (используется $m$ раз — для всех элементов $i$-й строки $C$);
- для каждого столбца $j$ матрицы $B$ — величина $\text{col}(j)=\sum_{k=1}^{q/2} b_{2k-1,j}b_{2k,j}$
  (используется $n$ раз).

## Алгоритм

Скалярный вариант — два подготовительных фрагмента и один основной
([[Векторные алгоритмы]] §1.3, алгоритмы 16–18):

**Подготовка $A$** (вектор `row`):
```
for i=1:n
  row(i) = A(i,1)·A(i,2)
  for k=2:q/2
    row(i) = row(i) + A(i,2k-1)·A(i,2k)
  end for
end for
```
**Подготовка $B$** (вектор `col`): аналогично, `col(j) = Σ B(2k-1,j)·B(2k,j)`.

**Основной фрагмент**:
```
for i=1:n
  for j=1:m
    C(i,j) = -row(i) - col(j)
    for k=1:q/2
      C(i,j) = C(i,j) + (A(i,2k-1)+B(2k,j))·(A(i,2k)+B(2k-1,j))
    end for
  end for
end for
```
Инициализация $C(i,j)$ как $-\text{row}(i)-\text{col}(j)$ закрывает второе и третье
слагаемые формулы (3).

### Векторные варианты

Как и в классическом методе, скалярные операции сворачиваются в векторные. Через
**скалярное произведение** (алгоритмы 19–21): например
`row(i) = A(i,1:2:q)·A(i,2:2:q)^T` (нечётные элементы строки скалярно умножаются на
чётные). Доступ смешанный. Перестановка циклов даёт варианты через **покомпонентное
произведение** векторов `.*` (алгоритмы 22–25, `ikj`- и `jki`-варианты со
строками/столбцами; вводится вектор-столбец единиц $w_l$). Выбор варианта — по способу
доступа к памяти или по наибольшей длине вектора ([[Векторные алгоритмы]] §1.3).

## Сложность

Число скалярных **умножений**:
$$\underbrace{n\cdot q/2}_{\text{подгот. }A} + \underbrace{m\cdot q/2}_{\text{подгот. }B}
  + \underbrace{n\cdot m\cdot q/2}_{\text{основной}} = q\Bigl(\tfrac{n}{2}+\tfrac{m}{2}+\tfrac{nm}{2}\Bigr),$$
против $q\cdot n\cdot m$ в классическом методе. Для квадратных матриц, отбрасывая младшие
степени, — **двукратный выигрыш** по умножениям. Число сложений при этом растёт
примерно в полтора раза, так что асимптотика остаётся $O(n^3)$ — метод не меняет
порядок сложности, лишь снижает дорогую константу при умножениях
([[Векторные алгоритмы]] §1.3).
