# Метод прогонки

**Метод прогонки** (англ. Thomas algorithm) — экономичный прямой метод решения СЛАУ
с **трёхдиагональной** матрицей: прямой ход исключает поддиагональ и вычисляет
прогоночные коэффициенты, обратный ход восстанавливает неизвестные. Базовый
последовательный метод предполагается известным; ниже — его **параллельный** вариант
из методички.

## Параллельный метод встречных прогонок

В [[Параллельные алгоритмы]] §3.3 как пример применения формулы ускорения с учётом
коммуникаций (см. [[сетевая-деградация-и-коммуникации]]) разбирается **двухзадачный**
параллельный алгоритм **метода встречных прогонок**. Идея: систему делят пополам и
ведут две прогонки навстречу друг другу.

### Три шага алгоритма

1. **Прямые ходы прогонок (параллельно).** Первая задача выполняет прямой ход
   **правой** прогонки для уравнений первой половины системы; вторая — прямой ход
   **левой** прогонки для второй половины. Оба прямых хода идут одновременно.

2. **Обмен прогоночными коэффициентами.** Две соседние задачи обмениваются
   прогоночными коэффициентами двух соседних уравнений из **середины** системы
   (отнесённых к разным задачам). После прямого хода третье неизвестное оказывается
   исключённым, и из этой пары уравнений находятся два принадлежащих им неизвестных.
   Это **единственная коммуникация** алгоритма: каждая задача отсылает и принимает
   пару коэффициентов.

3. **Обратные ходы (параллельно).** Первая задача — обратный ход **правой** прогонки
   для первой половины уравнений; вторая — обратный ход **левой** прогонки для второй
   половины. Снова одновременно.

### Характеристики (ускорение)

Длительность единственной коммуникации $t_к$ **не зависит** от размерности $n$, тогда
как время арифметики растёт: $t_a = t_a(n)$. Подставляя $p=2$ в формулу с учётом
коммуникаций (20), получаем:

$$S = \frac{2}{1 + t_к/t_a(n)}. \tag{21}$$

- При **малых $n$** ($t_к \gt t_a(n)$) ускорение $S \lt 1$ — параллельный счёт
  **медленнее** последовательного.
- С ростом $n$ время арифметики растёт, $S$ проходит через 1 и стремится к **2**
  (предел двухзадачного алгоритма), когда $t_к/t_a(n) \to 0$.

Здесь $w = t_к/t_a$ — коэффициент **сетевой деградации**; см.
[[сетевая-деградация-и-коммуникации]] и [[ускорение-эффективность-масштабируемость]].
