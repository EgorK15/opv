# Модификация матрицы внешним произведением

Одна из двух основных операций **второго уровня** (наряду с [[gaxpy-и-saxpy|gaxpy]]):
$$A=A+xy^{T},\qquad x\in\mathbb{R}^{n\times 1},\ y\in\mathbb{R}^{m\times 1},\ A\in\mathbb{R}^{n\times m}.$$

Сокращённо — **м.м.** Связана с векторной операцией **внешнее произведение** $xy^{T}$,
результатом которой является матрица (ранга 1). [[Векторные алгоритмы]] §1.1

## Выражение через saxpy

Операция допускает запись через [[gaxpy-и-saxpy|saxpy]] — наиболее удачную векторную
операцию с точки зрения аппаратных возможностей. Различают два варианта:

```
Алгоритм 1. Через столбцовое saxpy
for j = 1:m
    A(:,j) = A(:,j) + x·y(j)      % столбцовое saxpy
end for

Алгоритм 2. Через строчное saxpy
for i = 1:n
    A(i,:) = A(i,:) + x(i)·yᵀ     % строчное saxpy
end for
```

В Алгоритме 1 цикл перебирает **столбцы** $A$: здесь $z$ и $y$ из saxpy — это столбец
$A(:,j)$ в левой и правой частях присваивания, $\alpha=y(j)$, а столбец $x$ обозначает
сам себя. В Алгоритме 2 цикл перебирает **строки**: $z$ и $y$ — строка $A(i,:)$,
$\alpha=x(i)$, а строка $x$ есть $y^{T}$. [[Векторные алгоритмы]] §1.1; [[Лекции]] §3.1

## Сложность и сравнение с gaxpy

- **Арифметика** — $2nm$ флопов (столько же, сколько у [[gaxpy-и-saxpy|gaxpy]]).
- **Коммуникации** — больше, чем у gaxpy. При gaxpy матрицу $A$ достаточно переслать
  из «медленной» памяти в «быструю». При модификации внешним произведением $A$ —
  ещё и **результат**, который нужно вернуть обратно: коммуникационные издержки
  возрастают **вдвое**. По этому критерию дахру неизменно выигрывает, хотя на
  практике разница может быть не столь драматична. [[Векторные алгоритмы]] §1.1

Из-за этого алгоритмы [[умножение-матриц|умножения матриц]], основанные на
модификации внешним произведением (kij и kji в классификации Ортеги), отсеиваются
при выборе наилучшего — они уступают gaxpy-алгоритмам (jki, ikj) по коммуникациям.

## Роль в разложениях

Модификация внешним произведением — естественная матричная запись шага обновления
подматрицы в прямых методах:

- [[LU-разложение]] — на каждом шаге исключения оставшаяся подматрица обновляется
  как $A=A+xy^{T}$ (ранг-1 коррекция строкой и столбцом множителей);
- [[разложение-Холецкого]] — аналогичное ранг-1 обновление симметричной подматрицы.

Эта связь и делает операцию (вместе с gaxpy) фундаментом всей вычислительной
линейной алгебры на матричном уровне. [[Векторные алгоритмы]] §1.1

## Родственные операции

Известны более «экзотические» варианты, например `ssyr2` из LAPACK:
$$A=A+\alpha xy^{T}+\alpha yx^{T}.$$
В методичке изложение, следуя Голубу, ограничено двумя базовыми операциями второго
уровня. [[Векторные алгоритмы]] §1.1
