# Голуб (Gene H. Golub)

Джин Голуб (1932–2007) — американский математик, один из ведущих специалистов по
**вычислительной линейной алгебре**. Соавтор классической монографии «Matrix
Computations» (Голуб и Ван Лоан), на которую опирается весь курс.

## Вклад

- **Нотация записи параллельных алгоритмов** ([[Модели]] §1.2.2): дополняет
  [[модель-задача-канал|модель задача/канал]], конкретизируя содержание задач. Один набор
  инструкций пишется для всех задач (своя ветвь по номеру задачи $\mu$); язык близок к
  синтаксису MATLAB (`a(1:n)`, `A(1:n,1:n)`, блоки $A(n_1{:}n_2,n_3{:}n_4)$). Голуб
  называет задачу процессором. Из топологий особо выделяет линию, кольцо, решётку и тор;
  соседи — `left/right`, `east/west/north/south`. Коммуникации: `send`/`recv` (сети),
  `put`/`get` (общая память), критический интервал, барьер; распределения данных —
  **линейное** и **циклическое**.
- **Классификация алгоритмов умножения матриц** по матричной/векторной операции
  («классификация Голуба», в отличие от лаконичной классификации Ортеги по порядку циклов)
  ([[Векторные алгоритмы]] §1.2). Источник тезиса о выгоде [[блочные-алгоритмы|блочных
  алгоритмов]]: умножение $k\times k$ блоков — $2k^3$ флопов на $2k^2$ элементов данных.
