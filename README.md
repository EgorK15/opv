# Основы параллельных вычислений — материалы и ответы

Учебные материалы и подготовленные ответы к экзамену по курсу «Основы параллельных вычислений».

## Содержимое

| Файл | Описание |
|---|---|
| `Ответы.md` / `Ответы.pdf` | Ответы на все 38 вопросов по **методичкам Д.Л. Головашкина** (с формулами, алгоритмами и ссылками `[Книга, §]`, со встроенными рисунками). |
| `Ответы_по_лекциям.md` | Ответы по **конспекту лекций** (покрыты вопросы 3–13 и 15–20; остальное в лекциях не освещено и помечено). |
| `вопросы.txt` | Список экзаменационных вопросов. |
| `markdown/` | Исходные книги и лекции, конвертированные из PDF в Markdown (текст + извлечённые рисунки/формулы). |
| `*.pdf` (в корне) | Исходные учебные пособия и конспект лекций. |
| `pdf_build/` | Скрипт сборки `Ответы.md` → PDF (`render.js`). |

## Как это сделано

- **PDF → Markdown:** конвертация выполнена пакетом [`marker-pdf`](https://github.com/datalab-to/marker) на GPU (RTX 3090): 304 страницы, формулы переведены в LaTeX, таблицы — в Markdown.
- **Markdown → PDF:** рендеринг через `markdown-it` + KaTeX в HTML и печать headless-браузером Chrome (см. `pdf_build/render.js`).

### Пересборка PDF

```bash
node pdf_build/render.js
chrome --headless=new --no-pdf-header-footer \
  --print-to-pdf="Ответы.pdf" "file:///<abs-path>/pdf_build/output.html"
```
